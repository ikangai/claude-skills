# knowledge/

This directory holds YOUR calibration data — it ships empty by design.

- `kb.jsonl` — append-only records of model/task/prompt fits, written by
  `scripts/kb record` and `scripts/probe --record`. Calibration is specific to
  your machine (local model inventory, quantizations) and your tasks; it does
  not transfer between setups.
- `routing-table.md` — distilled recommendations, regenerated by `scripts/kb distill`.

Start with `scripts/kb prior --task-type <type>` (public-benchmark priors), probe
candidates with `scripts/probe ... --record`, and the knowledge base takes over
from there.
